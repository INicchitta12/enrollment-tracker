# Enrollment Tracker Dashboard

Interactive dashboard tracking enrollment trends across **Medicaid**, **CHIP & Medicaid
Child**, the **Basic Health Program (BHP)**, the **ACA Marketplace**, **Medicare**, and
**employer (ESI) coverage**.

**Live site:** `https://<username>.github.io/<repo-name>/`

---

## What's in it

| Tab | Contents |
|---|---|
| **Medicaid** | Enrollment KPIs with month-over-month deltas · renewal outcome cascade · procedural vs. ineligible disenrollment breakdown · cumulative impact strip · pre-unwinding peak comparison · total/adult enrollment trend · renewal outcome mix (ex parte vs. form) · state disenrollment rate ranking |
| **CHIP & Medicaid Child** | Total CHIP, derived Medicaid child, and combined child KPIs · enrollment trend · two pre-unwinding peak strips · cumulative impact strips · state ranking (toggle CHIP / Medicaid child) |
| **BHP** | Per-state enrollment trends (small multiples) · state share of national total |
| **ACA Marketplace** | OEP plan selection KPIs · post-OEP effectuated enrollment trend · year-over-year effectuated comparison · state ranking · metal tier and enrollment type composition · premium waterfall before/after APTC · cost sharing by metal tier |
| **Medicare** | MA-penetration KPIs · 3-year lookback strip · MA penetration trend · Original vs MA, Part D, and Aged vs Disabled compositions · state MA-penetration ranking |
| **Employer (ESI)** | Employer-sponsored coverage counts and premiums from annual survey sources |

Medicaid, CHIP, Marketplace, Medicare, and ESI tabs include a **state selector** — every
chart and figure on the tab recalculates for the selected state. BHP is national-scope
(four participating states).

## Methodology notes

**Marketplace post-OEP figures are effectuated enrollment, not plan selections.** The OEP
figure counts plan selections at the close of open enrollment; monthly figures thereafter
count consumers with effectuated coverage. These are different measures and the drop
between them is expected. Tooltips label each accordingly.

**National renewal outcome mix blends two sources.** December 2025 onward uses exact counts
from the source workbook. March–November 2025 uses percentages published in the CMS PDF,
where *pending* is derived as the residual after the four reported components. Values were
validated across the overlapping months and agree within 0.4 percentage points.

**Renewal outcome components are normalized to sum to 100%.** Rounding to one decimal can
leave columns at 99.9 or 100.2; components are rescaled proportionally so stacked bars
render cleanly. Adjustments are under a quarter of a percentage point.

**BHP reporting coverage varies by state**, so each state's chart plots only its reported
range and the national total reflects the single month all four states report (surfaced on
the tab). New York's figure is Essential Plan Expansion enrollment, reported in the BHP
series under a section 1332 waiver.

**Medicaid renewal denominators.** Renewed, disenrolled, and pending are expressed as shares
of *renewals due* in the reporting month, not of total enrollment. Procedural and ineligible
shares are expressed against total disenrolled.

**Medicare penetration uses the Part A&B denominator**, and the national series sums the 50
states + DC (excluding territories), so it runs ~1.4M below CMS's published national — both
disclosed on the tab. See `CLAUDE.md` for the California continuity restatement, the derived
Medicaid-child logic, and other adjustments.

## Updating the dashboard

The published `index.html` is **generated** — never hand-edit it. Edit `template.html` or the
build scripts and rebuild.

```bash
make install        # first time only — installs pinned deps
make update         # monthly: drop the new workbook at data/Enrollment_Tracker.xlsx, then rebuild
```

`make update` rebuilds `index.html`, refreshes the coverage table above, and prints the
monthly reminders (new snapshot PDF + caveats, Medicare drop, yearly cost-sharing refresh).
Run `make help` for all targets. Full step-by-step procedure and data caveats are in
`CLAUDE.md`. Commit and push to `main`; GitHub Pages redeploys within about a minute
(hard-refresh with Ctrl+Shift+R / Cmd+Shift+R to clear the browser cache).

A GitHub Action (`.github/workflows/build.yml`) rebuilds on every push/PR and fails if a
build assert trips, a placeholder is left unsubstituted, or the committed `index.html` is
stale.

## Technical notes

- Single self-contained HTML file — all data is embedded, no database or backend
- Charts render via Chart.js loaded from CDN, so **an internet connection is required** to view
- Tagged `noindex, nofollow` so the page is link-shareable but not surfaced in search results
- Renders in any modern browser; designed for desktop viewing

## Embedding in PowerPoint

Insert → Object → Create from File → select the HTML file. Requires internet access when
presenting. For a static slide, screenshot the tab you need instead.
